## 1. Problem Formulation & Theoretical Foundations

### 1.1 State Space Representation in $\mathbb{R}^d$
Let $\mathcal{S} = \{s_1, s_2, \dots, s_n\}$ be a finite set of $n$ discrete states embedded within a $d$-dimensional continuous Cartesian space $\mathbb{R}^d$. Each state $s_i \in \mathcal{S}$ is characterized by:
- A unique identifier: $\text{id}(s_i) \in \mathbb{N}$
- A coordinate embedding vector: $\mathbf{x}(s_i) = [x_{i,1}, x_{i,2}, \dots, x_{i,d}]^T \in \mathbb{R}^d$
- An optional semantic label: $\text{label}(s_i)$ denoting contextual meaning (e.g., waypoint, intersection, concept node).

### 1.2 Directed Transition Model
Transitions $\mathcal{T} \subset \mathcal{S} \times \mathcal{S}$ define the directed topological connectivity of the environment. Each directed transition $e = (s_i, s_j) \in \mathcal{T}$ is a tuple:
$$e = (\text{id}, s_i, s_j, c(e), \sigma(e), \rho(e), a(e))$$
where:
- $c(e) > 0$: nominal non-negative transition traversal cost.
- $\sigma(e) \in [0.0, 1.0]$: per-transition safety score.
- $\rho(e) \in [0.0, 1.0]$: operational reliability of the transition.
- $a(e) \in \{\text{true}, \text{false}\}$: dynamic availability flag indicating whether the edge is currently traversable.

### 1.3 Bad States & Invariant Safety Boundary
Let $\mathcal{B} = \{b_1, b_2, \dots, b_k\} \subset \mathcal{S}$ be the designated set of bad/hazard states (e.g., physical obstacles, no-fly zones, adversarial nodes, poisoned semantic concepts). The planner enforces the **strict hard-constraint invariant**:
$$\forall s \in \mathcal{P}, \quad s \notin \mathcal{B}$$
No path generated by the planner may visit a bad state under any operational condition.

### 1.4 Optimization Objectives
A valid path $\mathcal{P} = (s_{\pi_0}, s_{\pi_1}, \dots, s_{\pi_m})$ with $s_{\pi_0} = s_I$ and $s_{\pi_m} = s_G$ satisfies:
1. **Goal Reachability:** $\mathcal{P}$ terminates at $s_G$.
2. **Hard Safety Guarantee:** $\mathcal{P} \cap \mathcal{B} = \emptyset$.
3. **Cumulative Cost Minimization:** Minimize $C(\mathcal{P}) = \sum_{i=0}^{m-1} c(s_{\pi_i}, s_{\pi_{i+1}})$.
4. **Safety Margin Maximization:** Maximize the minimum Euclidean distance from any visited state to the nearest hazard:
   $$D(\mathcal{P}) = \min_{s \in \mathcal{P}} \min_{b \in \mathcal{B}} \|\mathbf{x}(s) - \mathbf{x}(b)\|_2$$
5. **Cumulative Reliability Maximization:** Maximize $R(\mathcal{P}) = \prod_{i=0}^{m-1} \rho(s_{\pi_i}, s_{\pi_{i+1}})$.
6. **Overall Multi-Objective Scoring Function:**
   $$\text{Score}(\mathcal{P}) = \alpha G - \beta C(\mathcal{P}) + \gamma D(\mathcal{P}) + \delta R(\mathcal{P})$$
   where $G \in \{0, 1\}$ is the goal reachability indicator and $\alpha, \beta, \gamma, \delta \ge 0$ are user-configurable trade-off weights.

## 2. Algorithm Selection: LPA* vs. D* Lite Analysis

### 2.1 Lifelong Planning A* (LPA*) Mechanics
LPA* (Koenig, Likhachev, Furcy, 2004) is a forward incremental search algorithm. It computes shortest paths from a fixed start state $s_I$ to all vertices, efficiently updating distance estimates when edge costs or graph topologies mutate.

Key internal variables maintained per vertex $u \in \mathcal{S}$:
- **$g(u)$:** Current shortest path estimate from $s_I$ to $u$.
- **$rhs(u)$:** One-step lookahead cost based on predecessor $g$-values:
  $$rhs(u) = \begin{cases} 0 & \text{if } u = s_I \\ \min_{v \in \text{Pred}(u), a(v, u)} (g(v) + c(v, u)) & \text{otherwise} \end{cases}$$

#### Vertex Consistency Classifications:
1. **Locally Consistent:** $g(u) = rhs(u)$ (no update required).
2. **Locally Overconsistent:** $g(u) > rhs(u)$ (a shorter path to $u$ was discovered; $g(u)$ is relaxed to $rhs(u)$).
3. **Locally Underconsistent:** $g(u) < rhs(u)$ (an edge on the path to $u$ became unavailable or more expensive; $g(u)$ is reset to $\infty$).

### 2.2 Priority Queue & Lexicographical Key Formulation
Inconsistent vertices ($g(u) \ne rhs(u)$) reside in a min-priority queue $U$. The priority key $\mathbf{k}(u) = [k_1(u), k_2(u)]$ is defined as:
$$\mathbf{k}(u) = \left[ \min(g(u), rhs(u)) + h(u, s_G), \quad \min(g(u), rhs(u)) \right]$$
where $h(u, s_G)$ is the admissible Cartesian heuristic to the goal.

Keys are ordered lexicographically:
$$\mathbf{k}(u) < \mathbf{k}(v) \iff \left( k_1(u) < k_1(v) - \epsilon \right) \lor \left( |k_1(u) - k_1(v)| \le \epsilon \land k_2(u) < k_2(v) - \epsilon \right)$$

### 2.3 Why LPA* is Superior for Fixed-Start, Dynamic Goal & Edge Workflows
| Criterion | Forward LPA* | Backward D* Lite |
|---|---|---|
| **Search Direction** | Start $s_I \to$ Goal $s_G$ | Goal $s_G \to$ Start $s_I$ |
| **$g$-value Dependency** | Depends only on $s_I$ (Goal-Independent) | Depends on $s_G$ (Goal-Dependent) |
| **Fixed Start / Changing Goal (Test Case 5)** | **Optimal:** Re-keys existing queue with $h(s, s_{G_{new}})$; $g$-values remain valid! | **Degraded:** Requires full $g$-value invalidation if goal moves. |
| **Moving Agent Scenarios** | Less suitable (start changes continuously) | Optimal (start moves, goal fixed) |
| **Assignment Alignment** | **Perfect Match:** Fixed initial state $s_I$, dynamic goals and dynamic edge modifications. | Available as benchmark comparison module. |

## 3. Data Structures & Architectural Design

### 3.1 Primary Data Structures
- **Graph Adjacency Lists:** `std::unordered_map<uint64_t, std::vector<EdgeInfo>>` for both forward (`successors_`) and reverse (`predecessors_`) lookups in $O(1)$ amortized time.
- **Priority Queue $U$:** Balanced binary search tree (`std::set<std::pair<Key, uint64_t>>`) combined with a reverse index map (`std::unordered_map<uint64_t, Key>`), supporting $O(\log |U|)$ insertion, key modification, and minimum extraction.
- **State Lookup Map:** `std::unordered_map<uint64_t, State>` and `std::unordered_map<uint64_t, std::vector<double>>` for Cartesian embeddings.
- **Hazard State Set:** `std::unordered_set<uint64_t>` supporting $O(1)$ membership checks for hard safety pruning.

## 4. Cartesian Heuristic Design & Admissibility Proof

### 4.1 Scaled Euclidean Cartesian Heuristic
In arbitrary graphs with continuous embeddings $\mathbf{x} \in \mathbb{R}^d$, transition costs $c(e)$ may not equal Euclidean distances $\|\mathbf{x}_u - \mathbf{x}_v\|_2$. Direct unscaled Euclidean distance could overestimate the true cost if $c(e) < \|\mathbf{x}_u - \mathbf{x}_v\|_2$, violating admissibility.

To guarantee mathematical **admissibility** ($h(u) \le h^*(u)$) and **consistency (monotonicity)** ($h(u) \le c(u, v) + h(v)$), we calibrate a global minimum cost ratio:
$$c_{\text{min\_ratio}} = \min_{\substack{e = (u, v) \in \mathcal{T} \\ a(e) = \text{true}, \|\mathbf{x}_u - \mathbf{x}_v\| > 0}} \frac{c(e)}{\|\mathbf{x}_u - \mathbf{x}_v\|_2}$$

The heuristic function is then defined as:
$$h(u, s_G) = c_{\text{min\_ratio}} \cdot \|\mathbf{x}(u) - \mathbf{x}(s_G)\|_2$$

### 4.2 Mathematical Proof of Admissibility
**Theorem 1 (Admissibility):** For any state $u \in \mathcal{S}$, $h(u, s_G) \le h^*(u, s_G)$.

*Proof:* Let $\mathcal{P}^* = (u = s_0, s_1, \dots, s_m = s_G)$ be the true shortest path from $u$ to $s_G$. By definition of $c_{\text{min\_ratio}}$:
$$c(s_i, s_{i+1}) \ge c_{\text{min\_ratio}} \cdot \|\mathbf{x}(s_i) - \mathbf{x}(s_{i+1})\|_2$$
Summing across all transitions on $\mathcal{P}^*$:
$$h^*(u, s_G) = \sum_{i=0}^{m-1} c(s_i, s_{i+1}) \ge c_{\text{min\_ratio}} \sum_{i=0}^{m-1} \|\mathbf{x}(s_i) - \mathbf{x}(s_{i+1})\|_2$$
By the triangle inequality in Euclidean space $\mathbb{R}^d$:
$$\sum_{i=0}^{m-1} \|\mathbf{x}(s_i) - \mathbf{x}(s_{i+1})\|_2 \ge \|\mathbf{x}(u) - \mathbf{x}(s_G)\|_2$$
Therefore:
$$h^*(u, s_G) \ge c_{\text{min\_ratio}} \|\mathbf{x}(u) - \mathbf{x}(s_G)\|_2 = h(u, s_G) \quad \blacksquare$$

## 5. Hard Safety Enforcement & Multi-Objective Balancing

### 5.1 Hard Bad-State Invariant Mechanism
Bad states are structurally excised from the search space:
1. $\forall b \in \mathcal{B}, \quad g(b) = \infty, \quad rhs(b) = \infty$.
2. Bad states are **never inserted into the priority queue $U$**.
3. Any transition $(u, v)$ where $u \in \mathcal{B}$ or $v \in \mathcal{B}$ is ignored during $rhs$ computation.
4. **Formal Guarantee:** The explored search tree and returned path $\mathcal{P}$ contain exactly zero bad states.

### 5.2 Safety Margin Barrier & Tradeoff Formulation
To balance total path cost against safety clearance margin $D(\mathcal{P})$ (Test Case 3), we implement an augmented effective edge cost:
$$c_{\text{eff}}(u, v) = c(u, v) + w_{\text{safety}} \cdot \max(0, D_{\text{threshold}} - D(v)) + w_{\text{rel}} \cdot (1 - \rho(u, v))$$
where:
- $D(v) = \min_{b \in \mathcal{B}} \|\mathbf{x}(v) - \mathbf{x}(b)\|_2$ is the Euclidean clearance of state $v$.
- $D_{\text{threshold}}$ is the desired minimum safe buffer.
- $w_{\text{safety}}$ is the repulsive penalty weight.

When $w_{\text{safety}} = 0$, the planner finds the absolute shortest cost path (even if close to obstacles). When $w_{\text{safety}} > 0$, the planner dynamically selects wider detour paths that maintain high clearance margins.

## 6. Dynamic Replanning Mechanics

### 6.1 Incremental Edge Updates (Availability / Cost)
When transition $e = (u, v)$ changes cost or availability:
1. Update $e$ in adjacency lists: $O(1)$.
2. Call `UpdateVertex(v)`: $O(\text{deg}_{\text{in}}(v))$.
3. Re-evaluate $rhs(v) = \min_{p \in \text{Pred}(v)} (g(p) + c_{\text{eff}}(p, v))$.
4. If $g(v) \ne rhs(v)$, insert or update $v$ in $U$: $O(\log |U|)$.
5. Call `ComputeShortestPath()`: only vertices topologically affected by the change are processed.

### 6.2 Goal State Relocation (Test Case 5)
When the goal moves from $s_{G_1}$ to $s_{G_2}$:
1. All existing $g$-values remain exact shortest distances from $s_I$.
2. Priority queue keys are updated with new heuristic $h(u, s_{G_2})$: $O(|U| \log |U|)$.
3. Search resumes incrementally until the new goal reaches consistency.

## 7. Complexity Analysis

### 7.1 Time Complexity
- **Cold Start Planning (Initial Search):** In the worst case, LPA* visits all vertices and relaxes all edges, yielding $O((|V| + |E|) \log |V|)$ identical to A*.
- **Incremental Replanning:** Let $\Delta V \subseteq V$ and $\Delta E \subseteq E$ be the subset of vertices and edges affected by the environmental perturbation. LPA* only processes inconsistent vertices, taking:
  $$T_{\text{replan}} = O((\Delta V + \Delta E) \log |U|) \ll O((|V| + |E|) \log |V|)$$
  Empirically yielding **17× to 49× speedups** on large benchmark graphs.

### 7.2 Space Complexity
- State and edge storage: $O(|V| + |E|)$.
- Distance maps ($g$, $rhs$) and priority queue: $O(|V|)$.
- Overall space complexity is strictly **linear**: $O(|V| + |E|)$.
