# User Manual

## Requirements

* A C++17 compiler (`g++` ≥ 9 or `clang++` ≥ 10).
* GNU `make`.
* No third-party libraries — the whole project is header/source files
  under `include/` and `src/`, no package manager needed.

## Build

```bash
make            # builds ./planner_demo
```

## Run the demonstration

```bash
./planner_demo
# or:
make run
```

This runs all six illustrative test cases from the assignment brief
(Basic Reachability, Bad State Avoidance, Safety Margin, Dynamic
Transition, Goal Update, Transition Addition), prints a per-case report
to stdout, and writes `results.csv` with the same data in machine-
readable form.

## Clean

```bash
make clean      # removes the binary and results.csv
```

## Using the planner in your own code

```cpp
#include "DStarLitePlanner.hpp"

PlanningProblem problem;
problem.initialState = 0;
problem.goalState = 3;
problem.badStates = {2};
problem.states = { State(0,{0,0}), State(1,{1,0}), /* ... */ };
problem.transitions = { Transition(/*id*/0, /*from*/0, /*to*/1,
                                    /*cost*/1.0, /*safety*/1.0,
                                    /*reliability*/1.0) /* ... */ };

DStarLitePlanner planner;                 // default safety/reliability weights
PlanningResult result = planner.plan(problem);

if (result.success) {
    // result.statePath, result.transitionPath, result.totalCost,
    // result.safetyScore are all populated.
}
```

### Replanning after the environment changes

Call `initialize()` once, then mutate the environment and call
`replan()` — this reuses the existing search tree instead of solving
from scratch:

```cpp
planner.initialize(problem);
auto r1 = planner.replan();

planner.setEdgeAvailability(transitionId, false); // an edge goes down
auto r2 = planner.replan();

planner.addTransition(newEdge);                    // a shortcut appears
auto r3 = planner.replan();

planner.addBadState(5);                             // a new hazard appears
auto r4 = planner.replan();

planner.updateGoal(newGoalId);                      // goal moves
auto r5 = planner.replan();
```

### Tuning the safety/cost trade-off

```cpp
DStarLitePlanner::Weights w;
w.safety = 6.0;       // penalize low-safety edges harder
w.reliability = 1.0;  // care less about reliability
w.proximity = 8.0;    // stay further from bad states
DStarLitePlanner planner(w);
```

## Project Layout

```
include/            Public headers (State, Transition, PlanningProblem,
                     PlanningResult, Planner interface, DStarLitePlanner)
src/                 Implementation (DStarLitePlanner.cpp) + the
                     demonstration driver (main.cpp)
docs/                DesignReport.md, ExperimentalResults.md,
                     UserManual.md (this file)
Makefile             `make`, `make run`, `make clean`
results.csv          Generated by running the demo (not checked in)
```
