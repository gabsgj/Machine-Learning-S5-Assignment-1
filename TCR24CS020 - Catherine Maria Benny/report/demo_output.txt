Interpretation: D* Lite here minimizes a COMPOSITE edge weight
beta*cost + gamma*safetyPenalty + delta*reliabilityPenalty (see
report.md section 11), so gamma does not merely change how the final
path is *scored* -- it changes which path the search actually selects.
At gamma=0 the search is pure cost minimization and picks the cheap,
unsafe Path 1. As gamma grows, the safety penalty on the near-miss
state dominates and the search switches to the more expensive but
safer Path 2. Bad-state avoidance itself remains a HARD constraint at
every gamma (edges into a bad state are always +inf, never merely
penalized) -- gamma only trades off cost against *proximity* to bad
states among paths that already avoid them entirely.
