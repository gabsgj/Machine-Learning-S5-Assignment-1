Safe Semantic Planner (D* Lite)

PCCST503 — Machine Learning, Assignment 1 Design of a Safe Semantic Planner in a Finite Cartesian State Space

Overview

A safety- and reliability-aware path planner over a finite set of states embedded in R^d. Given a start state, a goal state, a set of forbidden "bad" states, and a set of directed transitions (each with cost, safety, reliability, and availability), the planner computes a path that:

Reaches the goal
Never visits a bad state
Minimizes total transition cost
Maximizes the minimum distance from every visited state to the nearest bad state
Replans efficiently when the environment changes (goal moves, transitions appear/disappear, availability flips)

The algorithm is D Lite* (Koenig & Likhachev, 2002), chosen specifically for its ability to incrementally reuse prior search results instead of recomputing a full plan after every environmental change.

Design summary
State representation: integer id + embedding vector in R^d (models.State)
Data structures: adjacency dicts (successors/predecessors), an edge lookup dict, and D* Lite's g/rhs cost dicts backed by a binary heap priority queue
Heuristic: Euclidean distance between state embeddings (admissible)
Safety-aware cost: effective_cost = cost + w_safety/(safety+eps) + w_reliability*(1-reliability); bad states are excluded from the graph structurally so they can never be reached, rather than merely penalized
Dynamic replanning: update_transition() / add_transition() incrementally patch the search when the graph changes; set_goal() falls back to a full re-plan (a documented limitation of D* Lite's fixed-goal assumption)

Full design rationale, complexity analysis, and experimental results are in Design_Report.docx.

Experimental highlights

Incremental replanning consistently outperforms full re-planning, with the speedup growing as graph size increases (1.5x at 20 states, 3.2x at 200 states). See Design_Report.docx Section 10 for full data and discussion.
